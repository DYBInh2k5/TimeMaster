# TimeMaster - Ứng dụng Quản lý Thời gian

TimeMaster là một ứng dụng web hiện đại giúp bạn quản lý công việc và thời gian hiệu quả bằng kỹ thuật Pomodoro.

## 🚀 Tính năng chính

- **Bảng điều khiển (Dashboard)**: Theo dõi tổng quan năng suất, thời gian tập trung và số phiên Pomodoro hoàn thành.
- **Quản lý công việc (Task Management)**:
  - Thêm, xóa công việc.
  - Phân loại mức độ ưu tiên: Cao, Vừa, Thấp.
  - Tự động sắp xếp công việc theo trạng thái và độ ưu tiên.
- **Đồng hồ Pomodoro**:
  - Chu kỳ tập trung 25 phút, nghỉ ngắn 5 phút và nghỉ dài 15 phút.
  - Thông báo bằng âm thanh khi hoàn thành phiên.
  - Lưu lịch sử các phiên trong ngày.
- **Cài đặt cá nhân hóa**: Tùy chỉnh thời gian làm việc và nghỉ ngơi theo nhu cầu.
- **Lưu trữ cục bộ**: Mọi dữ liệu của bạn được lưu an toàn trên trình duyệt (LocalStorage).

## 🛠 Công nghệ sử dụng

- **React 19**
- **Vite**
- **Tailwind CSS v4**
- **Lucide React** (Icons)

## 📦 Cài đặt và Chạy thử

1. **Clone repository:**
   ```bash
   git clone <your-github-repo-url>
   cd time
   ```

2. **Cài đặt dependencies:**
   ```bash
   npm install
   ```

3. **Chạy ứng dụng ở chế độ phát triển:**
   ```bash
   npm run dev
   ```

4. **Mở trình duyệt:**
   Truy cập `http://localhost:5173` để trải nghiệm.

Dự án này được tạo ra cho mục đích học tập và quản lý cá nhân.
